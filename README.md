# WeKite

让微✉️更好用的轻量级增强模块 — 支持 LSPosed 与 Zygisk 双模式

> 🙏 **致谢（原始上游 [WeKit](https://github.com/cwuom/WeKit)）**：本项目基于上游 WeKit 二次开发，感谢原作者的开源贡献。
>
> 🤖 **本项目由 AI 编写**。
>
> ✅ **编译状态：CI 构建成功（最近一次：2026-10-07，v3.66）**
>
> - **LSPosed 版本**：APK 已签名，可安装测试（见下方安装说明）
> - **Zygisk 版本**：模块包可用，支持 Magisk / KernelSU（见下方安装说明）

WeKite 是一套针对微✉️的模块化增强方案：**共 62 个功能，分九大类**。核心设计是「不打扰、可开关、低开销」：

- **每个功能都有独立开关** —— 不需要的直接关掉，等于不存在；能调参数的会在设置里带一个齿轮图标，点进去就是详细配置。
- **全部本地运行**，不上传任何数据。AI 相关功能需要自备 API Key，消息只发往你自己填写的地址。
- **有账号风险的功能**（自动抢红包、自动接收转账、强制平板模式、检测单向删除好友）第一次开启会弹二次确认，需要你手动确认。

> 下面「功能一览」的分类与 App 内「功能」Tab 的分类一一对应，方便对照查找。

## 🚀 快速上手

1. **装**：LSPosed 模式装 APK；Zygisk 模式刷模块包（详见下方「📥 安装」）
2. **开**：LSPosed 里启用模块并勾选微✉️作用域；Zygisk 模式在 Root 管理器的模块 WebUI 里为微✉️打开注入
3. **进设置**：桌面 WeKite 图标，或 LSPosed 模块页里点 WeKite

设置页共四个 Tab：

| Tab | 内容 |
|------|------|
| **主页** | 模块是否已激活；已启用功能数 / 全部功能数；系统信息（微信版本、模块版本、构建时间、设备型号、Android 版本、当前加载器） |
| **功能** | 顶部可按名称搜索功能，搜索时能直接开关；下面是分类列表，末尾还有一类「已启用功能」汇总当前开着哪些。**普通功能就是一个开关**；名称旁有齿轮图标的功能点进去是详细配置 |
| **日志** | 运行日志 / 崩溃日志：查看、下拉刷新、分享、另存、清空 |
| **设置** | 配色（主题模式、自定义颜色、动态壁纸取色、种子颜色、调色板样式、颜色规格、**同时对微信生效**）、详细日志、显示加载完成 Toast、禁用版本适配、重置适配信息、导出 / 导入 / 清除配置、版本与检查更新、构建提交时间、开放源代码许可 |

⚠️ 界面类改动多数**需要完全退出微信再打开**才生效；个别功能会在设置里注明「重新进入聊天后生效」。

### 🤖 AI 聊天助手

「聊天」分类下的一个功能，因为选项较多，单独展开说明。核心：**收到新消息 → 分析情绪与意图 → 给出候选回复**，以卡片形式挂在对应消息下方（宽度与微信气泡对齐）。

**三条线路 / 两种模式**

- **对话模型（必填）**：任意 OpenAI 兼容接口，只填 base 网址或完整接口地址都行，配好后可点「测试」按钮验证连通性。
- **JEV 决策线路（可选，有 OpenRouter Key 即可）**：负责情绪判断与回复优选。只配这一条也能用（卡片仍有情绪与解读，但没有建议回复）。
- **手动模式**：卡片上列出候选回复（条数上限 1–6，默认 3），点一下填入输入框、长按复制、点「发」直接发送。
- **全自动模式**：满足规则时自动把选中的那条发出去。

**入口与开关**

- 聊天页标题栏右上角有一个实时状态徽标：灰 `AI`=未开 / 蓝 `AI`=分析已开 / `AI…`=分析中 / 蓝 `AI+`=全自动已开。点它进设置，长按标题栏「…」出本聊天的快捷菜单。
- 每个聊天（单聊 / 群聊）独立控制，可在**聊天详情页**或长按「…」菜单里开关三项：AI 自动分析并给建议 / 全自动回复 / 群里所有消息也处理。
- 群聊默认**只处理 @我的消息**；打开「群里所有消息也处理」才会处理全部消息。

**全自动回复的规则（都在设置里，括号内为默认值）**

| 选项 | 范围 / 说明 |
|------|------|
| 允许全自动回复（全局总闸） | 默认**关**。不开这个总闸，任何聊天的全自动都不会发消息 |
| 一次发送条数 | 1–3 条（默认 1） |
| 发送前等待 | 3–60 秒（默认 5）—— 这段是「可撤回窗口」，发出去之前还来得及拦 |
| 同一聊天冷却 | 10–600 秒（默认 60） |
| 每日上限 | 1–200 条 / 聊天（默认 20） |
| 免打扰时段 | 如 23:00 – 07:30，留空即不限制 |
| 群聊触发关键词 | 只在「只回@我」模式生效：@我 **或** 含关键词即回 |
| 高级设置 · 上下文条数 | 5–100 条（默认 30） |
| 高级设置 · 上下文预算 | 1000–48000 字（默认 8000） |

**其它**

- **回复优选**：候选生成后由 JEV 再挑一次。自动模式发它选中的那条；手动模式在它选中的候选上标「⭐推荐 N%」，**位置不动**（只标记不重排，不打断你对「第几条」的记忆）。默认开，可关。
- **人设与风格**：可以手写人设（对 AI 优先级最高，例如「我妈，说话随意但要有分寸」）；也可以让 AI 从你在该会话的历史发言里总结一份「风格画像」并模仿你的说话方式，画像可手动修正，还能设置过期自动重新生成（默认关）。
- **锁屏补扫**：锁屏期间漏掉的消息，解锁后该聊天再收到新消息时会自动补分析。
- **自动回复打标**：自动发出的回复会在消息列表里插一行只有你自己可见的系统提示，方便事后区分哪些是 AI 发的（对方看不到）。
- **隐私**：所有 Key 与配置都存在本地；消息内容只会发给你自己填写的线路地址。不配 Key 就完全不发任何请求。

| 莫奈引擎 | 按「设置 → 自定义颜色 / 动态壁纸取色 / 种子颜色 / 调色板样式 / 颜色规格」里配好的配色，给微信原生组件上色（输入框、按钮、卡片、图标等）。**想让配色作用于微信本身，需要打开「设置 → 同时对微信生效」。** 它是常驻组件，本身没有开关。 |
| 隐藏联系人通知抑制 | 被隐藏联系人的新消息通知在 push 进程里就被拦掉，避免"界面藏了、通知还在弹"。随「隐藏联系人」开关自动生效。 |

## 📥 安装

> ✅ **LSPosed 版本已可安装使用**（从 [Releases](https://github.com/SymonChu/WeKite/releases) 下载）。

### 方式一：LSPosed（Xposed 模式）

**适用**：已安装 LSPosed 框架的设备

1. 安装 [LSPosed](https://github.com/LSPosed/LSPosed) 框架（Android 8.0+）
2. 从 [Releases](https://github.com/SymonChu/WeKite/releases) 下载 APK 并安装
3. 打开 LSPosed → 模块 → 启用 WeKite
4. 勾选作用域：**微✉️（com.tencent.mm）**
5. 完全退出微✉️并重新打开

**设置入口**：桌面 WeKite 图标，或 LSPosed 模块页点击 WeKite。

**注意事项**：

- 支持微✉️ 8.0.65 ~ 8.0.76
- 需在 LSPosed 中启用模块并勾选作用域，否则功能不生效
- 部分功能修改微✉️界面，重启微✉️后生效

### 方式二：Zygisk（Magisk / KernelSU）

**适用**：已 Root 且启用 Zygisk 的设备（Magisk 或 KernelSU）

1. 从 [Releases](https://github.com/SymonChu/WeKite/releases) 下载 `WeKite-*-release.zip`（Zygisk 模块包）
2. 在 Magisk / KernelSU 中刷入模块
3. 重启设备
4. 打开 Root 管理器中的 WeKite 模块 WebUI，为微✉️打开注入开关

**特点**：

- 无需 Xposed 框架，Zygisk 原生注入
- KernelSU WebUI 管理注入目标

## ❓ 常见问题

**Q: 安装后找不到设置入口？**
A: LSPosed 模式需在 LSPosed 中启用模块并勾选微✉️作用域；Zygisk 模式入口在 Root 管理器的模块 WebUI。两者入口不同，请确认你用的框架。

**Q: 功能开关打开了，但没效果？**
A: 依次检查：① LSPosed 里是否已启用模块并勾选了微✉️作用域；② 是否完全退出微✉️再重新打开（界面类功能基本都需要重启微信）；③ 该功能是否有额外前提 —— 例如「AI 聊天助手」需要先填接口地址与 Key，「自动回复」还需要打开全局总闸。

**Q: 支持国内版微✉️吗？**
A: 核心功能（Xposed 模式）支持 8.0.65~8.0.76 全部版本。

**Q: 会不会上传我的聊天记录？**
A: 不会。模块不联网上传任何数据。只有你自己开启的 AI 功能会发请求，且消息只会发往你在设置里填写的地址。

**Q: 这些功能会造成账号异常吗？**
A: 涉及账号风险的功能（自动抢红包、自动接收转账、强制平板模式、检测单向删除好友）第一次开启都会弹二次确认，请自行评估后使用。

**Q: 换设备 / 重装后怎么保住配置？**
A: 设置 Tab 里有「导出配置」与「导入配置」，也可以「清除配置」重来。

**Q: 出问题要提供什么信息？**
A: 设置 → 日志 Tab 里有「运行日志」与「崩溃日志」，可直接分享或另存；报问题时把日志一起附上。
