# 通知进化

> 让微信的新消息通知更好用。通知栏直接回复、一键标为已读、原生对话样式。

## 类别

聊天

## 类型

可开关

## 描述

增强微信的新消息通知, 提供以下改进:

1. **通知栏直接回复** — 在通知栏直接输入并发送回复, 无需打开微信; 回复后自动标记已读, 可配「回复后清除通知里的消息历史」
2. **一键标为已读** — 通知栏按钮直接把会话标为已读并清掉通知
3. **原生对话样式 (MessagingStyle)** — 会话头像、按人分的消息历史 (最多 7 条)、群聊显示发送者名字
4. **通知内媒体显示** — 图片消息 (缩略图 / 大图) 与表情包消息可直接在通知里显示, 等待策略可调

## 注意

- 需要允许微信的消息通知; 系统通知渠道、锁屏隐私和免打扰规则仍可能影响最终显示
- 等待图片加载会受下载与网络情况影响, 超时后按纯文本显示
