# 群聊归拢

> 把群聊按分组收进主页若干条目，点开进入该分组的群聊列表

## 类别

聊天

## 类型

可开关 & 可点击

## 描述

微信主页的会话列表里，群聊本来和好友混在一起，新消息一多就把好友会话顶下去。开启本功能后：

- 主页列表里每个**分组**占一条入口条目（置顶显示），条目上写「分组名」+ `N 个群聊 · M 条未读` + 未读角标；
- 没有归入任何分组的群自动进「其他群」兜底条目，所以主页只剩好友会话 + 若干分组条目；
- 点条目打开该分组的群列表（未读优先排序），点任意群直接进入聊天；
- 分组条目的名字可以改；群聊本身的消息、未读、置顶状态都不动。

关掉开关或卸载模块后，群聊回到主页列表原位。

## 使用方法

1. 在「聊天」分类里打开「群聊归拢」。
2. 在主页**长按任意群聊** → 菜单里选「移入分组」→ 选已有分组，或「＋ 新建分组…」输入名字；选「移出分组」则回到「其他群」。
3. **长按分组条目** → 「重命名分组」，可改条目名字（「其他群」也能改）。
4. 点分组条目查看该分组的群列表；点齿轮/功能行可看全部分组。

## 实现要点

- 每条入口行是 `rconversation` 里一条 `username = wekite_groupagg_<分组 id>` 的真实会话行（配一条 `rcontact` 昵称），
  由微信按正常会话行渲染，本模块只把这一行的视图换成自绘样式。
  用真行而不是「往 adapter 里多插一个位置」，是为了避免所有 `position → 会话` 的偏移修正
  （ListView / RecyclerView 两条路径、滚动恢复、长按菜单、搜索都不需要改）。
- 摘除群聊用的是微信自己的「不显示该聊天」机制（`rconversation.parentRef = 'hidden_conv_parent'`），
  不删除任何数据；还原就是把 `parentRef` 改回空串。分组归属存在模块自己的偏好里（MMKV），不进微信数据库。
- 宿主收到新消息会重写会话行并抹掉 `parentRef`，所以挂了数据库更新监听：一旦它写成空，立刻改回，
  群不会先闪回主页列表。
- 锚点（2026-11-21 在 8.0.80/3220 与 8.0.79 Play 上字节级核验，均唯一命中）：会话列表 bind 锚宿主去重日志
  `Get Item duplicated: positionMaps: …`，点击锚 `MicroMsg.ConversationClickListener`，长按菜单锚
  `MicroMsg.ConversationLongClickListener` —— 都不写死混淆类名。
- 异常自愈（`群聊归拢守护`，常驻）：微信启动时若发现「开关已关但改动还在」或「入口行被微信清掉」，
  自动还原群聊显示，避免「群被藏了又没有入口」的死局。
