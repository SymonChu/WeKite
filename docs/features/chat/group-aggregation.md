# 群聊归拢

> 把所有群聊收进主页一个「群聊」条目，点开进入群聊列表

## 类别

聊天

## 类型

可开关 & 可点击

## 描述

微信主页的会话列表里，群聊本来和好友混在一起，新消息一多就把好友会话顶下去。开启本功能后：

- 主页列表里所有**未折叠的群聊**会被收进一条「群聊」条目（置顶显示），条目上直接显示 `N 个群聊 · M 条未读` 与未读角标；
- 点这条条目打开群聊列表（按未读优先排序，显示每个群的未读数），点任意群直接进入该群聊天；
- 群聊本身的消息、未读、置顶状态都不改动，只是不再占用主页列表位置；
- 已经用微信原生「折叠该群聊」收起过的群保持原样（它们在微信自己的「折叠的群聊」入口里）。

关闭开关或卸载模块后，群聊会重新回到主页列表原位。

## 实现要点

- 入口行是 `rconversation` 里一条 `username = wekit_groupagg` 的真实会话行（配一条 `rcontact` 昵称），
  由微信按正常会话行渲染，本模块只把这一行的视图换成自绘样式（标题 + 群数 + 未读角标）。
  用真行而不是「往 adapter 里多插一个位置」，是为了避免所有 `position → 会话` 的偏移修正
  （ListView / RecyclerView 两条路径、滚动恢复、长按菜单、搜索都不需要改）。
- 摘除群聊用的是微信自己的「不显示该聊天」机制（`rconversation.parentRef = 'hidden_conv_parent'`），
  不删除任何数据；还原就是把 `parentRef` 改回空串。
- 宿主收到新消息会重写会话行并抹掉 `parentRef`，所以挂了数据库更新监听：一旦它把 `parentRef`
  写成空，立刻改回，群不会先闪回主页列表。
- 异常自愈（`群聊归拢守护`，常驻）：微信启动时若发现「开关已关但改动还在」或「入口行被微信清掉」，
  自动还原群聊显示，避免出现「群被藏了又没有入口」的死局。

## 使用方法

在「聊天」分类里打开「群聊归拢」。点该功能行可直接查看群聊列表。若想让某些群回到主页，
需先在设置里关闭本功能（白名单能力尚未实现）。
