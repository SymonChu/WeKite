# 悬浮输入框

> 将聊天输入框改为悬浮卡片形式, 带有圆角、阴影和侧边距

## 类别

聊天

## 类型

可开关 & 可点击

## 描述

把微信聊天页底部的输入框改造成一张「悬浮卡片」: 与屏幕边缘留出侧边距、圆角、阴影,
不再是贴边的一条输入条。点击功能项可在弹窗中调节:

可配置项:
- **圆角半径**: 0~32 dp, 默认 24 dp
- **侧边距**: 0~32 dp, 默认 12 dp
- **底部间距**: 0~24 dp, 默认 4 dp
- **阴影强度**: 0~16 dp, 默认 4 dp
- **背景透明度**: 0~100%, 默认 100 (不透明)。调低后悬浮卡片自身背景变透明,
  透出会话页背景, 效果与「悬浮底栏」的透明可调一致

表情与工具菜单维持微信原样 (在输入行下方展开)。

## 使用方法

在模块设置中启用后, 点击配置各项参数。
